# CloudFlow

CloudFlow is a web application created as a **graduation project**.  
The application combines an **e-commerce system, cloud file storage, and an administration panel** for managing users, products, and orders.

The project was built using **PHP, JavaScript, CSS, and a MySQL database**.

---

# Overview

CloudFlow demonstrates how multiple web application modules can be integrated into one system:

- user authentication
- cloud file management
- product catalog
- order system
- administration dashboard

The project focuses on combining backend logic, database management, and a functional user interface.

---

# Features

## User Features

- User registration
- User login
- Personal dashboard
- File management (upload, view, download)
- Access to the e-shop
- Creating orders

---

## E-shop

- Product catalog
- Add products to cart
- Create orders
- Order history for users

---

## Admin Panel

Administrators have access to extended functionality:

- User management
- Product management
- Order management
- Dashboard overview
- Access to application data
